# A Little Diwali Surprise for Yashika 🪔

A simple, bright, responsive Diwali greeting website. It uses plain HTML, CSS and JavaScript and can be hosted free with GitHub Pages.

## Project files

```text
diwali-yashika/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
│   └── (put your photos here)
└── README.md
```

## Add your own photos — step by step

1. Choose up to six photos you want to show.
2. Open the website project folder.
3. Open its `images` folder.
4. Copy your photos into that folder.
5. Rename them exactly:
   - `photo-1.jpg`
   - `photo-2.jpg`
   - `photo-3.jpg`
   - `photo-4.jpg`
   - `photo-5.jpg`
   - `photo-6.jpg`
6. Keep the filenames and `.jpg` extension exactly as shown. If your photo is a PNG or WEBP, either convert it to JPG or change that image's `src` filename in `index.html`.
7. Open `index.html` in your browser. Your photos should appear in the “Our photos” section.
8. To use more or fewer photos, copy a `<figure class="photo-card">...</figure>` block in `index.html` and change its image filename and caption.

**Tip:** Use clear, well-lit photos. Images around 1200 pixels wide are more than enough for this page.

## Preview on your computer

Double-click `index.html` to open it in a browser. No installation or build step is needed. An internet connection is used only to load the optional Google Fonts; the page itself works without them.

## Publish free with GitHub Pages

1. Sign in to GitHub and create a new repository named `diwali-celebration`.
2. Upload the contents of this folder (the `index.html`, `css`, `js`, `images`, and `README.md` items). Upload the contents, not an extra nested project folder.
3. In the repository, open **Settings**.
4. Select **Pages** in the left sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**.
7. Click **Save**.
8. Wait a few minutes, then refresh the Pages screen. GitHub will show your live URL, usually:
   `https://YOUR-GITHUB-USERNAME.github.io/diwali-celebration/`

Whenever you replace photos or update the site, commit and push/upload the changed files to the same repository. GitHub Pages will publish the update.

## Personalise the message

Open `index.html` and edit the text inside the “A little note for my lovely Yashika” section. You can also change the heading, captions and footer text. Keep the HTML tags around the text intact.
