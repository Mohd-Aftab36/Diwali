# Diwali surprise for Yashika

## Replace / add your photographs

Put these files inside the `images` folder:

- `banner.jpg` — the large photo on the right side of the homepage banner
- `note.jpg` — the photo on the left side of the personal note
- `photo-1.jpg` through `photo-6.jpg` — the gallery photos

Use JPG files, or change the matching filenames in `index.html` if your images are PNG or WEBP. Keep the exact names shown above if you do not want to edit code.

## Upload to GitHub

1. Open your `Diwali` repository.
2. Upload the updated `index.html` to the repository root, replacing the old file.
3. Open the `css` folder and replace `style.css` with the supplied `css/style.css`.
4. Open the `js` folder and replace `script.js` with the supplied `js/script.js`.
5. Upload `banner.jpg` and `note.jpg` plus your six gallery photos into `images`.
6. Commit the changes and wait for GitHub Pages to deploy.
7. Open `https://mohd-aftab36.github.io/Diwali/` and press Ctrl+Shift+R.

## Photo gallery controls

Click or tap a gallery photo to open it larger. Use the left/right arrows or keyboard arrow keys to browse. Press Escape or the X button to close it.
